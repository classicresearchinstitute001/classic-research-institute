⚙️ Payment Settings - Paystack / Flutterwave

Configure your payment gateway to receive money on website

Get from https://dashboard.paystack.com → Settings → API Keys
Optional, alternative to Paystack

📚 How to Get Paystack Keys (2 mins):

  1. Go to https://paystack.com → Sign up as business (free)
  2. Complete KYC (BVN, ID, business docs) → Takes 1 day approval
  3. Dashboard → Settings → API Keys → Copy Public Key (pk_live_...) and paste above
  4. For testing now, use pk_test_... from Paystack test keys - payments won't be real but popup works
  5. Set bank account in Paystack dashboard → Money settles to your bank T+1 day
  6. Paystack fee: 1.5% + ₦100 capped at ₦2000 per transaction
